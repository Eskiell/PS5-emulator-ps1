# PSXS5 2.2.1

This release fixes the standalone PSXS5 Installer. Earlier installers could
mistake a leftover sandbox folder for a running PSXS5 app and refuse to install
even after the app was closed.

- The installer now checks the PS5's live process list for the PSXS5 title ID.
- If PSXS5 is running, it asks you to close the app and waits before downloading.
- If the process check is inconclusive, it stops without replacing app files.

Send `PSXS5Installer.elf` to the PS5 payload loader to install or update to
2.2.1. Games, BIOS, saves, and settings under `/data/PSXS5` are not replaced.
